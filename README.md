# Bruma - Website Institucional Premium

Website institucional moderno, sensorial e responsivo desenvolvido pela Webluma para apresentacao do projeto Bruma, um wine bar/restaurante autoral com cozinha sazonal, atmosfera intimista e posicionamento premium.

O projeto foi criado com foco em direcao visual, experiencia do usuario, percepcao de valor, storytelling gastronomico e conversao para reserva, contato e visita presencial.

## Sobre o projeto

Bruma e um website institucional conceitual desenvolvido para demonstrar como um restaurante, wine bar ou marca gastronomica autoral pode se posicionar de forma mais profissional, sofisticada e comercialmente atrativa no ambiente digital.

A proposta da marca e clara:

**Bruma - vinho, cozinha sazonal e encontros sem pressa.**

O site apresenta uma estrutura institucional completa, com:

- Pagina inicial com apresentacao da marca e atmosfera
- Hero section cinematografica
- Secoes de conceito, experiencia e menu em destaque
- Avaliacoes de clientes em carrossel
- Pagina de menu com pratos, imagens e selecao de vinhos
- Pagina de contato com formulario de reserva
- Informacoes de endereco, horarios e canais de contato
- Mapa integrado
- Footer institucional

O objetivo principal do projeto e mostrar como um website bem estruturado pode transmitir desejo, confianca, valor percebido e clareza comercial para uma marca gastronomica real.
